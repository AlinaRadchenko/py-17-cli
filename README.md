# THE N-DOORS

Текстова пригодницька гра для терміналу, в якій гравець
повинен пройти таємничі випробування, що ховаються за різними дверима.

## Plan

1. Створити головне меню з командами «грати», «результати», «допомога» та «вийти» та меню підтримує вибір пунктів за номерами 1–4.
2. Реалізувати гру з чотирма випробуваннями та трьома життями.
3. Відстежувати прогрес гравця та поточний стан гри.
4. Зберігати результати пройденої гри у файлі scores.json.
5. Обробляти некоректні вхідні дані та непередбачувані ситуації.

## How to run

Для запуску гри потрібен Python.

1.  Відкрий папку проєкту в терміналі.
2.  Запусти програму командою:

``` bash
python3 main.py
```

## Commands

У головному меню доступні такі команди:

-   `1` --- почати нову гру (PLAY).
-   `2` --- переглянути результати попередніх ігор (SCORES).
-   `3` --- переглянути правила гри (HELP).
-   `4` --- вийти з програми (QUIT).

Під час гри потрібно обирати двері за номерами від 1 до 4 та виконувати
випробування.

## Example

Приклад перегляду результатів у терміналі:

``` text
Твій вибір: 2
Аліна: 2, lost
```

## Design decisions

-   Для зберігання стану поточної гри використовується словник
    `game_dict`. У ньому зберігаються ім'я гравця, кількість життів,
    кількість пройдених випробувань, статус гри та відвідані двері.
-   На початку гри гравець має три життя. За кожне невдале випробування
    втрачається одне життя.
-   Кожні двері можна відвідати лише один раз. Після спроби вони
    зачиняються незалежно від результату.
-   Для перемоги потрібно успішно пройти щонайменше три з чотирьох
    випробувань.
-   Результати завершених ігор зберігаються у файлі `scores.json`, тому
    їх можна переглянути після перезапуску програми.


## Що відбувається, якщо видалити scores.json між двома іграми?

Під час завантаження результатів програма перехоплює FileNotFoundError і повертає порожній список.
Після завершення наступної гри створюється новий scores.json з новим результатом. 
Попередні результати, які були у видаленому файлі, не відновлюються.

## Помилка під час розробки

Під час перевірки номера дверей введення тексту замість числа могло спричинити помилку:
ValueError: invalid literal for int() with base 10: 'abc'
Номер дверей перевіряється як рядок: програма приймає лише значення 1, 2, 3 або 4.
Інші значення не перетворюються на число,
а супроводжуються повідомленням про помилку.
